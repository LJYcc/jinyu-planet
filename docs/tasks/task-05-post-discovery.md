# Task 5：星球广场与帖子详情阅读

**描述：** 将 Task 3 的读取 API 接入前端，实现 `/posts` 与 `/posts/:slug`。访客可按主题、关键词和页码分页浏览内容，并安全阅读 wangEditor 输出的帖子正文。前端从统一 API 成功响应的 `data` 读取业务数据，并从 `metadata` 读取分页信息。广场内容区使用顶部筛选工具栏、首条横向主卡、后续帖子列表和右侧信息栏的新版布局；首期不记录浏览量，也不接入点赞、评论或基于互动数据的热门排序，这些能力纳入第二期规划。

**前端数据边界：** 帖子和主题读取请求统一封装在 `app/services/post-api.ts` 与 `app/services/topic-api.ts`，页面只负责筛选状态、加载状态和展示。

**验收标准：**

- [x] `/posts` 支持主题筛选、关键词搜索、最新/精选排序和加载更多/下一页；Header 搜索在固定高度弹窗中以最多 100 条的单次请求展示公开帖子，Dialog 内容容器不设置内边距，输入与结果内容各自保留阅读留白、结果区滚动条贴住右边缘；结果区独立滚动且不写入 URL，锁屏时 Header 保持原有视口宽度、AI 助理使用视口左侧坐标定位，不进行运行时宽度计算；广场内部筛选、排序和分页直接应用当前列表状态，不持续写入 URL。
- [x] 精选排序只展示已发布且标记为精选的帖子，并按 `featuredRank` 与发布时间稳定排序。
- [x] 首期不依赖浏览量、点赞或评论数据；“最新”按发布时间排序，“精选”按人工精选字段排序。
- [x] 广场列表区使用当前新版布局：第 1 条结果作为主卡，其余结果进入列表；最新模式的主卡标题为“最新抵达”、列表标题为“继续探索”，精选模式对应“精选信号”和“更多精选”，内容不重复；短帖或链接等无摘要补充信息的内容不重复展示同一段文本。
- [x] 广场使用 flex 两栏布局；左侧内容区使用约 800px 的固定高度，工具栏固定在顶部，下面的结果容器占满剩余空间并使用 flex 布局，主卡自身不设置固定高度，图片与正文采用 flex 横向排列，区块标题垂直居中并保留上下约 10px 内边距，帖子列表自身使用纵向 flex 排列，列表区块按正常流式顺序排列，分页器在底部对齐，不覆盖列表内容。主卡不额外渲染隐藏主题节点，右侧本周主题图片直接使用图片元素，不添加仅用于样式的包装节点。有数据但不足 6 条时，缺少的卡片位置保留空白，不添加骨架或虚假内容；完全无数据时显示 `el-empty`。仅在总页数大于 1 时渲染分页器，但分页区域始终保留固定高度；列表区域不额外显示公开信号总数总结。切换分页时保留上一页内容直到新数据返回，避免页面闪动。
- [x] 右侧“本周主题”从启用主题表中按周随机选择，同一周内保持一致，跨周自动切换；主题名称和描述使用真实主题数据。
- [x] 右侧“参与本周主题”跳转投递页时携带当前主题的 `topic` 查询参数。
- [x] `/posts/:slug` 显示帖子元信息、标签、正文和按正文位置展示的图片；标签在标题信息区紧随主题展示，未设置标签时不占位。封面仅在星球广场列表/主卡展示，详情正文不单独渲染封面；详情不单独展示摘要（摘要仅用于列表卡片），标题区采用紧凑布局，标题桌面端最大 42px；详情使用约 960px 的居中内容容器，保留 wangEditor 支持的安全文字格式、H1-H6 标题、段落、对齐缩进、列表、表格、代码块、链接、图片、视频、引用和分割线等语义排版；分割线保留 wangEditor 的容器留白、圆角和线条样式；表格复用编辑器的固定布局、单元格尺寸规则和表头样式，不额外撑宽，详情区域只显示当前帖子内容，不展示右侧推荐、信号信息或投递入口；正文内容区固定为顶部背景带之后的首屏剩余高度，超出时内容区内部滚动，底部继续滚动可到达 footer；使用约 126px 桌面端、约 118px 移动端的深色紧凑上下文返回带，不显示未由编辑器实际支持的阅读目录；详情中不安全 HTML 不会执行。
- [x] 列表和详情具备加载、空结果、接口失败和 404 状态；从列表进入详情后，返回入口恢复进入详情前的搜索、主题、排序、页码和滚动位置状态；复制链接和返回广场入口可用。
- [x] 星球状态通过公开的 `/api/planet/stats` 统计 API 读取 active 匿名访客数、已发布信号总数和本周新增信号数；统计请求失败时显示不可用状态，不使用静态占位数字。

**验证：**

- [x] 人工检查筛选、搜索、排序、分页不会堆叠 URL 历史；Header 搜索弹窗的关键词、加载/空/失败状态和独立结果滚动（滚动条贴住右边缘、悬停显示不改变内容宽度、锁屏及解锁时固定 Header 与 AI 助理不闪动）、进入详情、返回详情前列表状态和滚动位置、详情页唯一返回入口和不存在 slug 可用。
- [x] 使用真实数据库数据检查星球状态的三项统计及统计接口失败时的不可用状态。

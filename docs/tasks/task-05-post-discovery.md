# Task 5：星球广场与帖子详情阅读

**描述：** 将 Task 3 的读取 API 接入前端，实现 `/posts` 与 `/posts/:slug`。访客可按主题、关键词和页码分页浏览内容，并安全阅读 wangEditor 输出的帖子正文。前端从统一 API 成功响应的 `data` 读取业务数据，并从 `metadata` 读取分页信息。广场内容区使用顶部筛选工具栏、首条横向主卡、后续帖子列表和右侧信息栏的新版布局；首期不记录浏览量，也不接入点赞、评论或基于互动数据的热门排序，这些能力纳入第二期规划。

**验收标准：**

- [x] `/posts` 支持主题筛选、关键词搜索、最新/精选排序和加载更多/下一页；Header 搜索可通过 URL 带入初始关键词，广场内部筛选、排序和分页直接应用当前列表状态，不持续写入 URL。
- [x] 精选排序只展示已发布且标记为精选的帖子，并按 `featuredRank` 与发布时间稳定排序。
- [x] 首期不依赖浏览量、点赞或评论数据；“最新”按发布时间排序，“精选”按人工精选字段排序。
- [x] 广场列表区使用当前新版布局：第 1 条结果作为主卡，其余结果进入列表；最新/精选模式使用对应的主卡和列表标题，内容不重复；短帖或链接等无摘要补充信息的内容不重复展示同一段文本。
- [x] `/posts/:slug` 显示帖子元信息、正文、图片、标签和相关推荐；详情使用深色上下文返回带、正文主栏和右侧信息栏，不显示未由编辑器实际支持的阅读目录；详情中不安全 HTML 不会执行。
- [x] 列表和详情具备加载、空结果、接口失败和 404 状态；复制链接和返回广场入口可用。

**验证：**

- [x] 人工检查筛选、搜索、排序、分页不会堆叠 URL 历史；Header 搜索初始关键词、进入详情、详情页唯一返回入口、相关推荐和不存在 slug 可用。

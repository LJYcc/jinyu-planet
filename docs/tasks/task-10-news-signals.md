# Task 10：新闻信号板块与星球简报（下一期候选）

**状态：** 候选，尚未开始。

**描述：** 为金鱼星球新增 `/news` 新闻信号板块和每日“星球简报”。它是可信新闻来源的聚合与导读能力，不是新闻全文转载站：仅通过正式新闻 API 或媒体 RSS 获取条目，公开页面展示标题、1–3 句短摘要、来源媒体、发布时间、授权配图（如有）与原文外链。首版控制在 3–5 个可信来源，优先保证来源清晰、摘要可核验与阅读体验。

**数据与处理边界：**

- 新增 `NewsSource` 保存来源名称、API/RSS 地址、启用状态和抓取配置；新增 `NewsItem` 保存标题、摘要、原文 URL、来源、发布时间、授权图片、分类和抓取时间；新增 `NewsDigest` 保存某日简报、生成时间和关联新闻条目。
- 定时任务默认每小时抓取一次，清洗后按原文 URL、标题相似度和来源去重；每日生成一份简报。任务必须记录失败原因，并提供受信任的手动触发入口，避免静默漏更。
- 不直接抓取新闻正文，不保存或公开展示未经授权的全文；新闻条目始终提供来源名称和安全的新窗口原文链接。
- AI 只能基于已保存的来源条目生成分类、关键词、中文短摘要与日报；不得补充、改写成事实或伪造来源。AI 输出保存生成时间，并关联所有可核验来源链接。
- 为后续 AI 数字人“星球电台”直播提供受控的当天 `NewsDigest` 读取边界；直播编排、互动与回放由 Task 11 单独实现。

**验收标准：**

- [ ] `/news` 可按时间读取已入库新闻，卡片只展示标题、短摘要、来源、发布时间、授权配图（如有）和原文外链。
- [ ] 已接入 3–5 个可信新闻 API/RSS 来源；定时任务可抓取、清洗、去重并记录失败，受信任维护入口可手动触发。
- [ ] 同一新闻不会因多个来源或重复抓取而重复展示；URL、标题相似度和来源去重规则可测试。
- [ ] 每日简报由已入库新闻生成，所有 AI 摘要可追溯到来源链接与生成时间，且不包含模型编造事实。
- [ ] 新闻页面具备加载、空结果、请求失败和来源不可用状态；外链以安全新窗口方式打开。
- [ ] 提供供数字人直播读取的当日简报数据边界；不得暴露来源 API 凭据或未经授权的新闻全文。

**验证：**

- [ ] 使用来源 RSS/API 的真实响应验证抓取、重复抓取、来源异常和空结果。
- [ ] 人工检查新闻列表、原文外链、每日简报的来源可追溯性，以及 AI 摘要与原始条目的事实一致性。
- [ ] 人工检查数字人直播素材读取简报时仍保留正确的新闻来源链接。

**依赖：** Task 3（公开读取 API）、Task 9（AI 服务能力）；数字人直播实现可在本 Task 的数据边界稳定后独立拆分。

**预计范围：** 大，涉及外部来源接入、定时任务、新闻数据模型、公开阅读页、AI 摘要以及后续直播内容复用边界。

# Task 11：AI 数字人“星球电台”直播（下一期候选）

**状态：** 候选，尚未开始。

**描述：** 为金鱼星球新增 AI 数字人“星球电台”直播。首版采用定时或预约直播：数字人围绕明确主题播报当天星球简报、站内精选信号与轻量资讯，并可在受控范围内回应匿名观众的主题问题和投稿。直播是站内内容的延展，不应变成无边界的泛娱乐直播间。

**业务与安全边界：**

- 直播页、播放器、弹幕/问答区和回放页必须持续显示“AI 数字人 / AI 生成内容”标识，不伪装真人，不暗示人工实时主持。
- 新增直播计划、直播场次、素材引用、观众投稿、问答、回放时间轴和回放摘要等独立数据模型。每项新闻素材保存可核验来源链接；每项站内素材只引用允许公开的信号链接。
- 主播仅可使用当前直播主题、Task 10 提供的已核验新闻简报和允许读取的公开站内内容生成播报或回答；无法从资料确认的内容必须明确说明，不得编造新闻、来源、用户投稿或主播经历。
- 匿名投稿上墙、主题问答与弹幕均经过服务端限流、长度/格式验证、内容安全检查和受信任筛选；原始输入不得直接拼接为数字人指令或直接公开。
- 数字人形象、TTS/音视频生成、实时传输和第三方供应商密钥都只能由服务端调用与管理。直播技术选型需在开工时确定，浏览器不得持有供应商密钥。
- 直播结束后生成可公开阅读的回放页，至少包含时间轴、文字摘要、播报中引用的新闻来源和公开信号链接；回放不得隐藏 AI 标识。

**验收标准：**

- [ ] 访客可查看即将开始、直播中和已结束的星球电台场次；场次、播放器和回放持续明确标识 AI 数字人内容。
- [ ] 管理侧可创建定时/预约直播并选择主题与可用新闻简报、精选信号素材；素材引用可追溯到原始来源或公开信号。
- [ ] 匿名访客可提交候选上墙信号与主题问题；请求受限流、校验与安全筛选保护，未审核内容不会直接展示或执行为模型指令。
- [ ] 数字人播报和问答只使用允许的素材范围；不存在依据时给出明确的不确定提示，不伪造事实或来源。
- [ ] 直播结束后自动或由受信任流程生成回放；回放包含时间轴、摘要、新闻来源及信号链接，并保持 AI 标识。
- [ ] 所有数字人和实时传输供应商密钥仅在服务端使用；客户端不获得秘密、永久媒体地址或未经授权的管理接口。

**验证：**

- [ ] 人工检查预约、直播中、无直播和回放状态，以及所有界面的 AI 标识。
- [ ] 使用正常、超频、恶意和无效的投稿/问答输入验证限流、校验、筛选与提示。
- [ ] 抽查直播播报和回放中的每条新闻或站内信号引用均能回到对应来源；验证无法确认的信息不会被编造成事实。
- [ ] 检查浏览器网络请求、环境配置和公开 API，确认不泄露数字人或实时传输供应商密钥。

**依赖：** Task 9（AI 服务）、Task 10（新闻简报）；站内精选信号读取复用 Task 3 的公开数据边界。

**预计范围：** 很大，涉及直播产品编排、外部数字人/音视频供应商、实时传输、内容安全、AI 来源约束、匿名互动、回放与运营维护流程。
